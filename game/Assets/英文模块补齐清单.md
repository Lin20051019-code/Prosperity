## 三、缺口②：语言切换入口（0.25 天）

`BargainState.language`（默认 "zh"）**全项目无任何赋值点**——CSV 层的英文也切不过去。方案（推荐 A+B）：

- **A. 主菜单语言按钮**：MainMenu 加 `Language` 按钮，点击切换 `BargainState.language = ("en"/"zh")` + `I18n.Reset()`，按钮文字直接显示 "EN / 中文"
- **B. 首启自动检测**：Start 时 `if (Application.systemLanguage == SystemLanguage.English) language = "en";`
- 切换后已加载数据的刷新：事件卡池（PenaltyCardPanel 需重载 CSV——建议语言切换只在主菜单/进局前生效，局中切语言不做）

## 六、⚠ 已知风险项（程序必读）

**Custom 事件的中文名匹配失配**：`DiceRollController` 的事件处理用 `if (name == "台风")`、`"边境封锁"`、`"罗宾汉出没"`、`"伸出援手"` 等硬编码中文名做分支。英文 CSV 的 `eventName` 是英文（Typhoon 等）→ **英文局这些事件只剩数值效果、Custom 行为（传送/单骰/劫富济贫）全部失效**。
修法二选一：① CSV 英文版 eventName 列保持中文键+另加 `name_en` 显示列；② 代码改按 `effectType == Custom` + 事件ID 匹配。**推荐①**（不动逻辑，显示层走显示列）。此为当前英文模块**唯一的逻辑级缺陷**，其余均为文案接线。
