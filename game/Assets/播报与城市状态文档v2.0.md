## 一、设计总则：状态面板 vs 播报条的分工

| | 回答的问题 | 生命周期 |
|---|---|---|
| **城市状态面板**（右下） | "现在是什么局面？"（繁荣多少、什么阶段、本阶段规则在怎么扣我钱、短板是谁） | 常驻，持续显示 |
| **播报条**（顶部卷轴） | "刚发生了什么？"（换挡、交易、通胀、救援、事件） | 瞬时，2.5-4s |

M套件（萧条经济）的**持续数值后果必须写在状态面板脸上**（如"维持费 −30/回合"），播报条只播事件性变化——这是防"玩家不知道自己为什么在掉钱"的核心分工。

## 二、美术素材清单（已入项目，程序直接引用）

所有素材经 `tools/pixelate_asset.py`（块降采样+调色板量化+黑转透明+连通域保真+收边精修）处理，**统一像素风**（4px块、24-32色）。

| 素材 | 路径 | 规格 | 用途与显示参数 |
|---|---|---|---|
| 播报条卷轴背景 | `Assets/图片/播报条卷轴背景.png` | 1940×648 透明PNG | 顶部居中，RectTransform 约 **650×217**（≈33%等比缩放）；Image **Filter=Point**（Bilinear必糊）；CanvasGroup 淡出沿用现有代码 |
| 阳光光束 | `Assets/图片/阳光光束.png` | 2560×1440 透明PNG，alpha已阶梯量化 | 冲刺区全屏叠加，**Blend=Screen/Add**（QC结论：透明区不压暗、光束发光）；alpha呼吸 0.75~1.0 + 缓慢 ±2° 摆动 |
| 暗角 | `Assets/图片/暗角.png` | 1280×720 径向渐变透明PNG | 全屏叠加，危机 tint 冷蓝(120,140,180)、冲刺 tint 暖金(180,160,120)；**强度为程序可调参数（策划拍板：初始 0.2，试玩范围 0.15~0.35）** |
| 冲刺光点 ×4 | `Assets/图片/冲刺光点_1~4.png` | 140×148 ~ 380×388 透明PNG | 冲刺区漂浮粒子：6-10个实例随机位置，代码驱动上浮+缩放脉冲+alpha闪烁；显示尺寸 24~64px 随机 |
| 雨（Rain2D粒子） | `Assets/TJGeneratorLibEffects/Prefabs 2D/Weather/Rain2D.prefab` | 现成2D天气粒子（含材质/贴图/meta） | 实例化到 GameScene，排序在地图之上、UI之下；淡入淡出用 emissionRate/maxParticles 渐变（1s） |

**像素化管线**（以后新素材复用）：`python3 tools/pixelate_asset.py <输入> <输出> --mode <keep|cropband|blackalpha|vignette> [--block 4 --colors 32 --alpha-steps 4 --slice]`
- `cropband`=黑底横幅裁切收边（卷轴类）；`blackalpha`=光效黑转透明；`slice`=光点图集切元素；`vignette`=代码生成暗角

## 三、城市状态面板（右下，繁荣指数区域升级）

现有 `prosperityText`（仅"繁荣指数: N"）升级为四行信息，**全部代码动态创建，0新美术**：

```
┌──────────────────────────────────────┐
│ 繁荣指数  63 ▲        ▍危机区          │ ①数字+方向箭头（涨绿#4CC664/跌橙#FF8800）
│ ▓▓▓▓▓▓▓░░░┼────┼─────────🚩110      │ ②进度条：20→110全程；45/60两根换挡刻度
│ 维持费 -30/回合                       │ ③本阶段规则小字（随RefreshPhase更新）
│ 短板：莉兹（财富1640）                 │ ④短板行（回合末刷新）
└──────────────────────────────────────┘
```

| 行 | 内容 | 刷新时机 |
|---|---|---|
| ① 繁荣数字+箭头 | `63 ▲`（与上回合末比较） | 回合末（UpdateProsperity 已在回合末调用，箭头值取回合末快照） |
| ② 进度条 | 起点=失败线20，终点=胜利线110，45/60刻度小竖线，当前繁荣位置游标 | 回合末 |
| ③ 阶段角标+规则小字 | 【危机区】红#D93A2B + "维持费 −30/回合（恶名 −60）"；【常规区】灰白；【冲刺区】金#FFD933 + "分红 +20/回合" | RefreshPhase 内（换挡即变） |
| ④ 短板行 | `短板：{名}（财富{N}）`，并列取先遍历者 | **仅回合末**（NextTurn 的 currentTurn==0 分支，与 ApplyEconomyTick 同点）。**不可逐笔刷新**——短板身份实测每局换手6.3次，逐笔会闪 |

危机角标进场演出：闪红3下（复用 TurnIndicator 脉动模式），与换挡 P0 播报同步。
左上 RoundHUD（TurnIndicator.CreateRoundHud）**移除"繁荣 N"字样**，只留 `回合 X/14`+进度条——繁荣信息归状态面板，一处一事。

## 四、三档氛围系统（全屏，玩家"体感"到城市状态）

| 档位 | 画面层（从下到上：地图 → 氛围 → UI） | 进/出演出 |
|---|---|---|
| 危机区 | Rain2D粒子雨 + 暗角(冷蓝tint) + 可选画面压暗 | 进：雨1s淡入+暗角渐变；出：1s反向 |
| 常规区 | 无氛围层 | — |
| 冲刺区 | 阳光光束(Screen混合,呼吸+微摆) + 暗角(暖金tint) + 光点漂浮 | 进：光束1s淡入+光点渐现；出：1s反向 |

**换挡演出时序**（与播报/状态面板联动）：
```
0.0s  播报条P0：【警告】城市进入衰退期！市政启动救市…
0.3s  状态面板角标闪红3下
0.5s  雨淡入 + 暗角转冷蓝（1s）
0.5s  (M套件)【危机】维持费/通胀汇总播报 P1
```

实现要点：
- 全部氛围层用 **常驻 GameObject + 开关渐变**（不要 Instantiate/Destroy 往返GC）；挂在 GameScene 一个 `AtmosphereRoot` 下
- 暗角强度：`[SerializeField, Range(0.15f, 0.35f)] float vignetteIntensity = 0.2f;`（策划试玩拍板最终值）
- Rain2D 若在团结引擎出现紫黑材质/丢失着色器 → **降级方案**：暂用阳光光束同管线生成"雨幕贴图"（素材未生成，需要时跑 pixelate_asset.py 一次即可），代码滚动替代
- 光点池：6-10个 Image 实例循环复用，随机 spawn 上浮，出屏回收

## 五、播报条升级（BroadcastBar.cs 修复清单）

### 5.1 现有缺陷修复（必须）

| # | 缺陷 | 修复 |
|---|---|---|
| B1 | **P0 互踩丢消息**：跌破30告警与换挡播报同刻触发时，后者 StopCoroutine 杀掉前者，永远显示不全 | P0 打断当前条时，把被杀的条**塞回队首**（保留原优先级），而不是丢弃 |
| B2 | 队列满时 `DropLowest()` 实际丢队首（最旧），P2 刷屏可挤掉排队中的 P1 | 改为**优先丢队列中的 P2**（从队尾往前找第一个 P2），没有 P2 才丢队首 |
| B3 | v2.2 落地后危机回合末一次产生 4-6 条播报（维持费+通胀×N+抵制+繁荣变化），队列上限4必丢 | **回合末合并**（见5.2） |
| B4 | 繁荣播报无每回合限流（v1.0 文档A1规则未实现），UpdateProsperity 一回合被调数十次，|Δ|≥5 连播 | 加 `lastProsperityBroadcastRound`，**每回合至多1条**繁荣变化播报 |
| B5 | `TurnIndicator.FlashDanger()` 用"⚠"字符（系统字体豆腐块风险；当前无人调用属死代码） | 删除或改纯文字 |

### 5.2 回合末合并播报（M套件专属）

危机回合末，维持费+通胀合并为**一条**：
```
【危机】市政征收维持费；通胀吞噬现金 {总额}元（{被吞者名单}）
```
- 无通胀发生时：`【危机】萧条持续，市政征收维持费{30或60}元/人`
- 抵制加征警告保留独立 P0（v2.2 文档已有每局每人一次去重）
- 冲刺回合末：`【繁荣】经济腾飞，全城分红20元/人`（一条）

### 5.3 卷轴背景接入

1. `panel` 挂 Image，Sprite=`播报条卷轴背景`，**Filter=Point**，preserveAspect=true，RectTransform 约 650×217 顶部居中
2. 左侧优先级竖条：代码画 8px 宽 Image（叠在卷轴左端轴杆内侧），**P0红#A61E19 / P1铜金#9C7A2E / P2墨绿#4A5D3A**（羊皮纸底上用深色系，一脉相承砍价对话盒角色条）
3. 文字颜色：**深墨 #2A1F14**（羊皮纸底必须用深字，不能沿用白字）；P0 告警文字 **#8C1E12** 深红；保留现有 CanvasGroup 淡出
4. 字体走 `BargainState.GetSafeFont()`（团结引擎字体坑，勿直接内置字体调用）
5. 播报条宽度较文字短时：允许文字最多两行，fontSize 26-30，超出截断（阈值告警文案控制在40字内——见第六节文案已核对）
