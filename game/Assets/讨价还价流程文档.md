# 讨价还价完整流程文档

## 一、流程概述

讨价还价分为3个独立场景，通过 Additive 加载方式叠加在 GameScene 之上：

```
GameScene (Bargain触发)
  → 讨价还价_选卡 (人格卡选择)
    → 玩家选卡: 讨价还价_报价 (3轮报价)
      → 讨价还价_结果 (显示结果)
        → 确认 → 卸载结果场景 → 回到GameScene
    → AIvsAI: 自动结算 → 讨价还价_结果
```

## 二、触发条件

在 `DiceRollController.HandleBuilding` 中，玩家走到他人房产时：
- `BuildingPanel.ShowRented` 显示"支付租金"和"Bargain"两个按钮
- 点击 Bargain → 调用 `StartBargain(tileIndex, tokenIndex, data)`
- `StartBargain` 将数据存入 `BargainData` 静态类，然后 `LoadScene("讨价还价_选卡", Additive)`
- GameScene 的 `Update()` 检测 `BargainResult.completed`，完成后调用 `HandleBargainResult`

## 四、人格卡属性表

| 卡牌 | 首轮优势 | 改价幅度 | 声望变化 |
|------|---------|---------|---------|
| 交个朋友 | -10% | +20% | +5 |
| 实价交易 | -10% | -10% | +3 |
| 看人下菜 | +30% | +20% | -2 |
| 极限压价 | +30% | -20% | -3 |

### AI选择逻辑
```
x = (声望 + 利己值) / 25
x ≥ 3 → 极限压价(卡4)
x ≥ 2 → 看人下菜(卡3)
x ≥ 1 → 实价交易(卡2)
x ≤ 0 → 交个朋友(卡1)
```

## 五、报价公式

### 首轮报价
```
卖方首轮 = 市场价 × (1 + 首轮优势 + 声望/200)
买方首轮 = 市场价 × (1 - 首轮优势 - 声望/200)
```

### 第2轮报价（3个选项）
```
报价1: 上轮报价 + 价差 × (30% + 改价幅度)
报价2: 上轮报价 + 价差 × (50% + 改价幅度)
报价3: 上轮报价 + 价差 × (70% + 改价幅度)
```
- 买方价差 = 卖方报价 - 买方报价（正数→买方加价）
- 卖方价差 = 买方报价 - 卖方报价（负数→卖方降价）

### 第3轮报价（3个选项）
```
报价1: 上轮报价 + 价差 × (40% + 改价幅度)
报价2: 上轮报价 + 价差 × (60% + 改价幅度)
报价3: 上轮报价 + 价差 × (80% + 改价幅度)
```

### 成交判定
- 买方报价 ≥ 卖方报价 → 成交，成交价 = 两者平均值
- 3轮后仍未重叠 → 交易失败，支付租金

## 七、GameScene 回调

`DiceRollController.Update()` 检测 `BargainResult.completed`：
1. 读取 `BargainResult.isSuccess` 和 `BargainResult.finalPrice`
2. 清除 `BargainResult.completed`
3. 调用 `HandleBargainResult(success, finalPrice)`
4. 成功：买方支付成交价，房产所有权转移
5. 失败：买方支付租金
6. 等待 `turnDelay` 后 `NextTurn()`

## 八、AI vs AI 自动结算

在 `BargainSelectController.AutoResolveAndGotoResult()` 中：
1. 双方AI各自选择人格卡
2. 计算首轮报价
3. 如重叠 → 成交
4. 否则进行第2轮（随机选报价态度）
5. 如重叠 → 成交
6. 否则进行第3轮（随机选报价态度）
7. 如重叠 → 成交
8. 否则 → 失败
9. 直接跳到结果场景（跳过报价场景）
