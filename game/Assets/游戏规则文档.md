# SheNicest 游戏规则文档

## 1. 游戏概述

- **类型**：棋盘类策略游戏（类似大富翁）
- **玩家**：1个玩家 + 3个AI，共4人
- **角色名字**：
  - 玩家：莉兹·玛吉
  - AI1：罗斯韦尔
  - AI2：露丝
  - AI3：徐丰
- **回合顺序**：玩家 → AI1 → AI2 → AI3 → 玩家 → ...（循环）
- **场景流程**：MainMenu → GameScene（BargainScene 以附加场景按需加载）
- **最大回合数**：15回合

## 2. 棋盘

- **格子总数**：32格（等距视角菱形环）
- **格子间距**：36px/18px（X/Y轴步长）
- **Board 配置**：anchoredPosition Y=356，scale 2.2（正常）/ 2.8（玩家移动时缩放）
- **格子类型**：
  - 房屋块（建筑格）
  - 惩罚块（惩罚事件）
  - 事件块（全局事件）
  - 奖励块（奖励事件）
  - 火车块(1)（火车站）
  - 基金会（公益中心）
  - 起点
- **路灯街道装饰**：在惩罚格、事件格、奖励格外侧各放置一个路灯街道（场景块 路灯街道1/2.png 交替使用），作为格子子物体，尺寸与建筑精灵一致（68.66×111.92）
- **路径顺序**（tilePath，逆时针）：
  - R9_Start(起点) → R8 → R7 → R6 → R5 → R3 → R2 → R1 → T9_TrainTR(火车站) → T8 → T7 → T5 → T4 → T3 → T2 → T1 → T0_Charity(公益中心) → L1 → L2 → L3 → L4 → L5 → L6 → L8 → B0_Start(火车站) → B1 → B2 → B3 → B4 → B5 → B6 → B8 → 回到 R9_Start

## 3. 移动规则

### 3.1 骰子
- 每回合掷出**两个骰子**，点数独立随机（可以相同）
- **步数 = 骰子1 + 骰子2**（范围 2~12）
- 玩家掷骰后 **1.5 秒自动行动**（无需点击按钮确认），AI 自动确认
- 骰子以图片形式显示（骰子1-6），有数字快速变化动画

### 3.2 移动方式
- 角色**跳跃前进**（抛物线弧线，jumpHeight=20px）
- 落地时格子**向下弹跳**（建筑/子物体保持不动，bounceDuration=0.15s）
- **玩家移动时**：视角放大到 2.8 倍并聚焦玩家，移动完成后等 0.5 秒再缩回 2.2 倍
- **AI 移动时**：视角保持 2.2 倍不变
- 移动期间**所有玩家的状态栏隐藏**，移动完成后恢复
- 拖拽在非操作状态下可用（`!IsBusy` 时）
- **移动速度参数**：moveStepDuration=0.18s，jumpHeight=20，bounceDuration=0.15s，postMoveDelay=0.5s

### 3.3 经过起点
- 正常移动经过起点（Tile_R9_Start）时，获得**工资 200 元**
- 坐火车传送**不触发**工资

### 3.4 道路修缮（额外投骰）
- 奖励卡"道路修缮"触发后，当前玩家获得**额外一次投骰机会**
- `rerollNextTurn` 为 `bool[4]`，每个玩家独立标记
- AI 触发时 AI 自己获得额外回合，不会泄漏到玩家回合

## 4. 格子效果

### 4.1 建筑格（房屋块）
- 每个建筑格有独立数据：等级(0-3)、所有者(-2=政府, 0-3=玩家)
- **建筑价值**：
  - 0级：100元（baseValue + 0×100）
  - 1级：200元
  - 2级：300元
  - 3级：400元
- **市场价格** = TotalValue × (繁荣指数+50)/100 × (0.96~1.04 随机)
- **租金** = 市场价格 × 10%
- **升级费用**：购买(0→1)=100元，升级(1→2)=100元，升级(2→3)=100元
- **政府所有（空地）**：
  - 玩家：弹出面板，可选择花费 100 元购买，变为 1 级房屋
  - AI：`WillingToSpend` 且资金足够时自动购买
- **自己的房产**：
  - 玩家：可选择花费 100 元升级
  - AI：`WillingToSpend` 且 `CanUpgrade` 且资金足够时自动升级
- **他人的房产**：
  - 必须支付租金
  - 玩家：弹出面板，可选"支付租金"或"Bargain"
  - AI：现金占比 ≥ `cashPreference`（`WillingToSpend`）时选择 Bargain，否则支付租金
- 建筑外形随等级变化（buildingSprites[0-3]）

### 4.2 惩罚格（惩罚块）
- 弹出红色卡牌面板（抽卡滑入 + 翻牌动画）
- 随机抽取一个惩罚事件，效果作用于**当前玩家**
- 播报显示事件名 + 具体效果说明（如"触发惩罚: 冲动消费 — 失去现金200"）
- 7个惩罚事件（`penalty_events.csv`）：

| 事件 | 效果类型 | 效果 |
|------|----------|------|
| 冲动消费 | CashLoss | 现金 -200 |
| 闯红灯被抓 | ReputationLoss | 声望 -10 |
| 道德败坏 | CashLoss | 资产最低玩家现金 -50 |
| 资金紧缺 | SellProperty | 随机卖一块地产（退还价值一半） |
| 恶性竞争 | CashAndRepLoss | 自己和随机玩家声望 -5 |
| 年久失修 | DowngradeProperty | 随机自己的房产降级 |
| 生病休息 | SkipTurn | 跳过下回合 |

### 4.3 事件格（事件块）
- 弹出蓝色卡牌面板
- 随机抽取一个全局事件，效果作用于**所有玩家或特定玩家**
- 播报显示事件名 + 具体效果说明
- 8个事件（`event_events.csv`，已删除"边境封锁"）：

| 事件 | 效果类型 | 效果 |
|------|----------|------|
| 地震 | DowngradeProperty | 随机一条边的所有房产降一级 |
| 黑帮火拼 | CashLoss | 所有玩家现金 -100 |
| 台风 | Custom | 所有玩家回到起点，不获得工资 |
| 丑闻 | ReputationLoss | 财富最高玩家声望 -10 |
| 公益晚会 | ReputationGain | 所有玩家声望 +5 |
| 交通事故 | SkipTurn | 随机一名玩家下回合被跳过，触发时和实际跳过时各播报一次 |
| 发现金矿 | CashGainPercent | 所有玩家现金 +5% |
| 邻城暴雷 | CashLossPercent | 所有玩家现金 -5% |

### 4.4 奖励格（奖励块）
- 弹出金色卡牌面板
- 随机抽取一个奖励，效果作用于**当前玩家**
- AI 奖励格自动处理（不弹面板），播报显示奖励名 + 具体效果说明
- 9个奖励（`reward_events.csv`）：

| 奖励 | 效果类型 | 效果 |
|------|----------|------|
| 中奖 | CashGain | 现金 +200 |
| 助人为乐 | ReputationGain | 声望 +10 |
| 交通补贴 | Custom | 传送到火车站 |
| 商战 | Custom | 随机获得一个非自己的房产（免费） |
| 道路修缮 | Custom | 可以再投一次骰子 |
| 结盟 | ReputationGain | 自己和随机玩家声望 +5 |
| 人脉 | Custom | 按当前价值随机购买一个非自己的房产 |
| 装修 | Custom | 随机自己的房产免费升级 |
| 伸出援手 | Custom | 最富玩家 -200，最穷玩家 +200 |

### 4.5 火车站（火车块）
- 两个火车站：Tile_T9_TrainTR 和 Tile_B0_Start
- 走到火车站可选择花费 **50元** 传送到另一个火车站
- **玩家**：弹出面板选择是否乘坐
- **AI**：50% 概率乘坐
- 坐火车**不触发**经过起点工资

### 4.6 起点（Tile_R9_Start）
- 每次正常移动经过起点获得**工资 200 元**

### 4.7 公益中心（基金会，Tile_T0_Charity）
- 玩家：弹出面板，可花费 **400元** 获得 **12声望**
- AI：声望 ≤ 所有玩家平均值且现金足够时自动捐款

## 5. Bargain 系统

### 5.1 触发条件
- 玩家停在他人房产上时，可选择"支付租金"或"Bargain"
- AI 停在他人房产上时，现金占比 ≥ `cashPreference`（`WillingToSpend`）时选择 Bargain，否则支付租金
- BargainScene 以附加场景加载（`LoadSceneMode.Additive`），结束后卸载

### 5.2 流程
1. **人格卡选择**：4张人格卡，翻转动画（正面1秒→翻转→显示卡背属性），卡牌统一尺寸 925×913
2. **AI 选卡**：基于 `(声望 + 利己值) / 25` 自动选择，玩家无法替 AI 选择
3. **3轮报价**：每轮玩家从3个报价按钮中选择（按钮显示具体报价金额，如"买210元"）
4. **成交判定**：买方报价 ≥ 卖方报价则成交，取中间价
5. **结果显示**：报价面板显示买卖双方名字（如"卖方(罗斯韦尔): 220元" / "买方(莉兹·玛吉): 180元"）
6. **结果处理**：
   - 成功：房产转移给买方，买方支付成交价
   - 失败：买方支付租金

### 5.3 AI 自动策略
- AI vs AI：`AutoResolveBargain()` 完全自动结算，不显示 UI
- AI vs 玩家：AI 自动选择人格卡和报价，玩家只控制自己的选择
- AI 人格卡选择公式：`x = (声望 + 利己值) / 25`
  - x ≥ 3 → 极限压价
  - x ≥ 2 → 看人下菜
  - x ≥ 1 → 实价交易
  - x < 1 → 交个朋友

### 5.4 人格卡属性

| 卡名 | 首轮优势 | 改价幅度 | 声望变化 |
|------|----------|----------|----------|
| 交个朋友 | -10% | +20% | +5 |
| 实价交易 | -10% | -10% | +3 |
| 看人下菜 | +30% | +20% | -2 |
| 极限压价 | +30% | -20% | -3 |

### 5.5 报价计算
- **首轮报价**：
  - 卖方 = marketPrice × (1 + 首轮优势 + 声望/200)
  - 买方 = marketPrice × (1 - 首轮优势 - 声望/200)
- **后续轮**：报价 = 当前报价 + 价差 × (系数 + 改价幅度)
  - 第2轮系数：0.30 / 0.50 / 0.70
  - 第3轮系数：0.40 / 0.60 / 0.80
- 报价按钮显示具体金额（如"买210元"）

### 5.6 跨场景数据传递
- `DiceRollController.BargainData`（静态类）：传递 marketPrice、sellerIndex、buyerIndex、声望、利己值、sellerName、buyerName 等
- `BargainController.BargainResult`（静态类）：返回 success/finalPrice/completed
- `BargainController.Start()` 读取 BargainData 自动初始化
- `BargainResult` 仅在 `ConfirmResult`（玩家确认）或 `FinishBargain`（AI vs AI）时设置
- `DiceRollController.Update()` 检测 `BargainResult.completed` 后调用 `HandleBargainResult`

## 7. AI 策略

| 行为 | 策略 |
|------|------|
| 骰子 | 自动掷两个骰子，步数 = 两骰子之和 |
| 建筑格（空地） | `WillingToSpend` 且资金足够时自动购买 |
| 建筑格（自己的） | `WillingToSpend` 且 `CanUpgrade` 且资金足够时自动升级 |
| 建筑格（他人的） | `WillingToSpend` 时选择 Bargain，否则自动支付租金 |
| 火车站 | 50% 概率花费 50 元传送 |
| 奖励格 | 自动处理，不弹面板 |
| 公益中心 | 声望 ≤ 平均值且现金 ≥ 400 时自动捐款 |
| Bargain 人格卡 | 基于 (声望 + 利己值) / 25 自动选择 |
| Bargain 报价 | 自动计算，AI vs AI 完全自动结算 |
| 道路修缮 | AI 自己获得额外投骰，不泄漏到其他玩家 |

## 8. 繁荣指数系统

- **繁荣指数** = 最穷玩家财富值 / 40（向下取整）
- **游戏结束条件**：
  - 繁荣指数 ≤ 20：所有玩家失败
  - 繁荣指数 ≥ 100：所有玩家大获全胜
  - 15回合结束：根据繁荣指数判定结果
- 繁荣指数影响建筑市场价格（繁荣越高，价格越高）
- 右下角显示"繁荣指数: XX"

## 9. 卡牌系统

### 9.1 卡牌面板（PenaltyCardPanel）
- 三种类型：惩罚（红）、事件（蓝）、奖励（金）
- 抽卡动画：从屏幕下方滑入（EaseOutBack 弹跳）→ 停顿 → Y轴翻牌
- 卡牌尺寸：500×600
- 字体：VonwaonBitmap
- 事件数据从 CSV 加载（3个文件，共24个事件）
- 播报显示事件名 + 具体效果说明（effectDescription）

### 9.2 人格卡翻转（BargainController）
- 正面展示1秒 → 翻转（scaleX 1→0→1，0.6秒）→ 切换到卡背精灵 + 显示属性文字
- 卡背精灵：交个朋友/实价交易/看人下菜/极限压价
- CardInfoText 在运行时由 `SetupCardBacks()` 创建
- 卡牌统一尺寸：925×913

## 10. TileTooltip 悬停提示

- 鼠标悬停格子上显示信息小窗口
- 使用 `文本框.png` 作为 Sliced 背景（280×110，内边距 30/15）
- 字体：VonwaonBitmap-16px
- 文字颜色：深棕色 (0.35, 0.16, 0.06)
- 建筑格显示：等级、所有者、市场价格
- 特殊格显示：功能说明

## 11. 播报系统

- 屏幕顶部中央显示播报条（BroadcastBar）
- 所有操作都会播报：掷骰子、购买建筑、升级、支付租金、触发事件、经过起点、Bargain、跳过回合等
- 事件/奖励/惩罚播报包含**具体效果说明**（不只是事件名）
- 显示 2.5 秒后自动淡出（0.5秒）
